# Achaar House — Pickle Catalog Website

A beautifully crafted, multi-page catalog website for **Achaar House**, an authentic Indian handcrafted pickle brand established in 1985.

## Pages

| Page | Description |
|---|---|
| `index.html` | Homepage — hero, bestsellers, categories, brand story, testimonials |
| `catalog.html` | Full product catalog with filter bar & product detail modal |
| `about.html` | Brand story, founder timeline, team, and values |
| `contact.html` | Contact form with inquiry types, FAQ accordion |

## Tech Stack

- Pure **HTML5** & **Vanilla CSS**
- **Google Fonts** — Cormorant Garamond + Outfit
- No frameworks, no build tools — open `index.html` directly in a browser

## Design

- Warm terracotta, cream & gold palette
- AI-generated product photography (consistent brand style)
- Scroll animations, glassmorphism navbar, responsive layout
- Mobile-friendly with hamburger navigation

## Images

All product images in `/images/` are AI-generated in the Achaar House visual style — terracotta Indian kitchen, glass jars, natural ingredients.
